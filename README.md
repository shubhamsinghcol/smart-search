# Smart:Search

**Find the card, even when you can't remember the exact words.**

Type a few things you remember. Smart:Search finds the cards that match and puts the best ones first.

```text
smart:Noncaseating granulomas + transmural inflammation + cobblestone mucosa
```

## What you get

**Search by clues, not exact wording.**  
Type what you remember, in any order. No quotes, no extra search syntax.

**It speaks medicine.**  
Search *Lasix* and find *furosemide*. Search *IBD* and find *inflammatory bowel disease*. *Crohn's* and *Crohn disease* are the same thing to it.

**Start from symptoms.**  
Type the findings you remember and get the cards for the conditions that go with them.

**Long notes are no problem.**  
It matches individual passages to find the part of a big note that matters.

**Different wording, same card.**  
With the optional smarter-matching download, it can find a card even when your phrasing looks nothing like the note's.

**Nothing to set up.**  
No account, no API key, no extra apps. It gets ready in the background while you study.

**Nothing to worry about.**  
It never changes your notes, cards, or scheduling. Use `smart:` when you want it, and Anki searches like normal when you don't.

## Get started

1. Install add-on **1117931988** from [AnkiWeb](https://ankiweb.net/shared/info/1117931988) and restart Anki.
2. Open Browse and type `smart:` followed by what you remember.
3. *Optional:* go to **Tools → Smart Search options** and click **Download semantic model** for smarter matching.
